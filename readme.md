# YearnCraft Mod Pack

A non-exhaustive guide to connecting to the server.

## Prism Client instructions

I am using what is called the Prism Client, available here: <https://prismlauncher.org/>

Sign in with your Microsoft account.

Add a new instance of the game using the "Add Instance" button.
![alt text](https://github.com/KirbyPaint/yearncraft/blob/main/img/step_1.png)

You can name the instance whatever you want. We are using version 26.2 of the base game. Then, scroll this window down. Under Mod Loader, select Fabric.
![alt text](https://github.com/KirbyPaint/yearncraft/blob/main/img/step_2.png)

Make sure you choose Fabric version 0.19.3 (the latest version). Then click OK to set it.
![alt text](https://github.com/KirbyPaint/yearncraft/blob/main/img/step_3.png)

Select your new instance, and choose Edit on the left-hand side.
![alt text](https://github.com/KirbyPaint/yearncraft/blob/main/img/step_4.png)

Select Mods from the left-hand column, then choose "Add file." Add all of the mods from the mods folder in this mod pack.
![alt text](https://github.com/KirbyPaint/yearncraft/blob/main/img/step_5.png)

You should then be able to launch the game with the Launch button on the bottom-right.
